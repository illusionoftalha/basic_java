# Basic Java

> A beginner-friendly collection of Java tutorials covering core programming concepts — from data types and control flow to methods and OOP fundamentals.

---

## Overview

A structured set of Java programs written as standalone tutorial files, organized under `Java/Tutorials/`. Each file demonstrates a specific concept with clean, readable code. Ideal as a first reference when learning Java or revisiting the fundamentals.

---

## Topics Covered

- Variables and data types (`int`, `double`, `char`, `boolean`, `String`)
- Operators (arithmetic, relational, logical)
- Control flow (`if/else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Methods (parameters, return types, overloading)
- Arrays (single and multi-dimensional)
- Object-Oriented Programming basics (classes, objects, constructors)
- Encapsulation and access modifiers

---

## Project Structure

```
basic_java/
└── Java/
    └── Tutorials/
        └── *.java    # Individual topic files
```

Each `.java` file is self-contained and can be compiled and run independently.

---

## Getting Started

### Prerequisites

- JDK 8+ installed
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or just the terminal

### Run a file

```bash
cd Java/Tutorials/src
javac -d ../bin HelloWorld.java
java -cp ../bin HelloWorld
```
